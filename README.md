# Africa Untamed

Africa Untamed is a wildlife story-telling project built to showcase and celebrate the beauty of Africa's ecosystems, and the urgent need to protect them.

# Live Demo

[https://cassandrathedev.github.io/africa-untamed/](https://cassandrathedev.github.io/africa-untamed/)

# About

Africa Untamed is not a website, it is an experience. Built as a frontend portfolio project, it combines immersive parallax scrolling, scroll-triggered animations, and real conservation data to tell a story that moves through Africa's most extraordinary ecosystems: the Serengeti, the rainforests of Central Africa, the open savanna, and beyond.

The project is structured as seven chapters, from the beauty of Africa's wildlife to the conservation crisis threatening it, ending with a call to action linking to real organisations working to protect these species.

# Features

 -	**Cinematic parallax** - full-screen section backgrounds with scroll-driven depth
 -	**Chapter navigation** - fixed dot navigation on the right side for storytelling context
 -	**Scroll reveal animations** - staggered fade and slide animations as each section enters view
 -	**Custom cursor** - gold cursor with a trailing ring that reacts to hover interactions
 -	**Counter animations** - conservation statistics count up as they scroll into view
 -	**Real conservation data** - accurate endangered species counts and statistics
 -	**Fully responsive** - adapts across mobile, tablet and desktop
